# Nibiru 视觉方向

方向：安静、精密、可长时间工作的私有创作空间。界面结构来自用户要求和 Safari 中检查的 NovelAI；暖灰米白与橄榄绿取自用户提供的参考截图。

- 左导航强调当前位置，管理员入口只对管理员可见。
- 图片是主体。配置留在底部，进阶模式需要时才展开。
- 实际批次放在右侧，历史页承担搜索与日期浏览。
- 留白、细分隔线和低对比容器保持层级，不靠大量卡片装饰。
- 登录视觉由 Creative Production / 内置 ImageGen 生成，保存在 public/assets/studio-art.png；属于页面装饰，不作为模型生成结果。
